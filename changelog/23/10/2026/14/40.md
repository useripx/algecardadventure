## Batch 33: Integrasi Universal Runtime & UI Prosedural Easter Egg AI Math Companion Chatbot (Pemicu Tahan Logo 3 Detik di Semua Layar)

### 📌 Ringkasan
Batch 33 menuntaskan integrasi menyeluruh dan aktivasi universal sistem Easter Egg AI Math Companion Chatbot (Groq API LLM + Persona Prof. Hopper 🦗 & Pip 🐜) di seluruh 6 scene permainan (*01_SplashScreen*, *02_Level*, *03_MissionCard*, *04_AlgebraCardBoard*, *05_TrueOrFalse*, *06_ScoreResults*). Sistem dirancang menggunakan arsitektur non-intrusif berbasis `ChatbotRuntimeBootstrap.cs` dan pembuatan UI prosedural `EnsureProceduralUI()` pada `ChatbotUIController.cs` sehingga tidak memodifikasi atau merusak berkas serialisasi YAML scene eksisting, sekaligus menjaga stabilitas pengujian CLI test runner tanpa eror native Unity ECall.

### 🚀 Perubahan Utama

1. **Modul Bootstrap Runtime Otomatis (`ChatbotRuntimeBootstrap.cs`):**
   - Menjalankan `[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterSceneLoad)]` yang otomatis terpanggil setelah scene apa pun selesai dimuat saat Unity Play Mode aktif.
   - Menginspeksi hierarki game object aktif untuk mendeteksi objek logo resmi game (`Logo`, `LogoImage`, `LogoPlaque`, `TOP_LOGO_TITLE`).
   - Mengaktifkan `raycastTarget = true` pada komponen Image logo dan menautkan komponen `LogoLongPressTrigger` secara otomatis.
   - Menjamin singleton `ChatbotUIController` selalu hidup di root `DontDestroyOnLoad`.

2. **Pembangunan UI Prosedural 1:1 Prototipe (`ChatbotUIController.cs`):**
   - Mengimplementasikan `EnsureProceduralUI()` yang secara mandiri merakit antarmuka modal berstandar `Docs/Ui Template/chatbot/code.html` jika belum dipasang di Inspector.
   - Canvas Overlay (`SortingOrder: 100`) dan Dark Backdrop semi-transparan (`#050D1A` alpha 88%).
   - Panel dialog utama kayu bertema fantasi bergaris tepi emas (`#D9A633`) ukuran 980x1680 px.
   - Header Bar berisi tombol navigasi tutup `"◀ BACK"`, avatar Prof. Hopper & Pip, dan status indikator hijau.
   - Tiga Quick Chips interaktif: `"💡 Pindah Ruas"`, `"🔍 Apa Variabel?"`, dan `"📜 Petunjuk Misi"`.
   - ScrollRect obrolan dua arah dengan balon pesan hijau tua (user) dan cokelat kayu (bot) serta indikator mengetik.
   - InputField dengan placeholder dan tombol `"KIRIM ❯"`.

3. **Pertahanan Anti-ECall & Stabilitas CLI Test Runner:**
   - Menambahkan try-catch defensif di sekeliling `AudioManager` dan instansiasi UI.
   - Menggunakan cast `(object)` untuk null check `UnityEngine.Object` agar tidak memicu internal call native Unity C++ engine di lingkungan .NET CLI test runner.

4. **Pembaruan Konfigurasi Proyek & Kasus Uji Otomatis:**
   - Mendaftarkan `ChatbotRuntimeBootstrap.cs` ke `AlgeCardAdventure.Runtime.csproj`.
   - Menambahkan pengujian `TC_CHAT_07` (deteksi logo runtime) dan `TC_CHAT_08` (state transisi modal & IsChatOpen) pada `ChatbotTests.cs` dan `ChatbotTestRunner`.
