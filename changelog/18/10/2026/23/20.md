## Batch 22: Resolusi Interaktivitas Klik & Polish Visual Layar 04 (Algebra Card Board)

### 📌 Ringkasan Masalah & Permintaan Pengguna
Menindaklanjuti laporan dan screenshot Yogi Ario (*"oke masuk ke layar selanjutnya ini gabisa ditekan appaun ini gimana tolong cek dan perbaiki buat implementation plan dulu si lebih tepatnya sebelum mengerjakan"*):
1. **Akar Masalah UI Mati Total (Tidak Merespons Sentuhan Klik/Tap):**
   - **Pohon Transform Terputus:** 175 dari 184 `RectTransform` pada scene YAML sebelumnya memiliki array `m_Children: []` kosong. Akibatnya, `GraphicRaycaster` bawaan Unity tidak dapat menelusuri hierarki objek untuk mendeteksi event klik pada tombol-tombol anak.
   - **GUID Input Module Usang:** Objek `EventSystem` menggunakan GUID lama `StandaloneInputModule` (`guid: 4f231c4fb786f3946a6b90b886c48677`) yang tidak kompatibel dengan konfigurasi New Input System Unity 6, alih-alih `InputSystemUIInputModule` (`guid: 01614664b831546d2ae94a42149d80ac`).
   - **Mode Canvas Kamera:** Canvas diset ke `RenderMode: 1` (Screen Space Camera) dengan plane distance yang rentan drop raycast.
   - **Polusi Raycast Target:** Hampir seluruh elemen teks statis dan panel gambar dekoratif memiliki `m_RaycastTarget: 1`, menghalangi sinyal klik pointer mencapai tombol slot di lapisan bawah.
2. **Isu Visual & Konten:**
   - Avatar Profesor Bug masih menggunakan kotak placeholder warna hijau polos (`AvatarBox`).
   - Kartu variabel kedua menampilkan teks `"and"` (`VarCard_and`) alih-alih `"y"`.
   - Plakat kanan atas memiliki 3 teks bertumpuk saling tumpang tindih (*"LEVEL 1"*, *"EASY"*, *"Variables"*).

### 🛠️ Rekonstruksi Total Hierarki Scene (`04_AlgebraCardBoard.unity`)
Menggunakan script rekonstruksi hierarki murni `scratch/build_scene_04_clean_tree.py` dengan arsitektur pohon `UINode` rekursif dan alokator ID monotonik unik:
1. **Pohon Hierarki 100% Terhubung:**
   - 178 `RectTransform` kini memiliki array `m_Children` yang terisi lengkap dan akurat menghubungkan setiap node induk ke anak-anaknya.
   - Total 752 objek serialisasi Unity dengan **0 duplicate IDs**.
2. **EventSystem Unity 6 Modern:**
   - Menggunakan komponen `InputSystemUIInputModule` (`guid: 01614664b831546d2ae94a42149d80ac`).
   - Terhubung secara resmi ke `m_ActionsAsset` (`guid: ca9f5fa95ffab41fb9a615ab714db018`) dan action point pointer `m_PointAction`.
3. **Canvas Screen Space Overlay:**
   - Mengubah `RenderMode: 0` (Screen Space Overlay) pada Canvas, memastikan raycast sentuhan/klik langsung dievaluasi di bidang viewport layar tanpa distorsi kamera.
4. **Pembersihan Raycast Target:**
   - Menonaktifkan `m_RaycastTarget: 0` pada seluruh teks instruksi, equation box, status pill, plakat, dan panel dekoratif.
   - Hanya objek interaktif (`Button` pada slot baris aljabar, sidebar kartu 0-9, variabel, operator, tombol CLEAR, D-Pad, dan footer tombol) yang memiliki `m_RaycastTarget: 1`.
5. **Penyempurnaan Visual & Konten:**
   - Memasang sprite maskot resmi `mascot_green_cricket.png` (`guid: 71a82e9b01c441118123456789012341`) menggantikan kotak hijau.
   - Memperbaiki kartu variabel menjadi `"y"` (`VarCard_y` dengan label teks `"y"`).
   - Menyederhanakan plakat kanan atas menjadi satu baris teks bersih `"Easy · Variables"` (font 24px bold cokelat tua).
