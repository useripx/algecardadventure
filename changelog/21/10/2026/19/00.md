## 📌 Ringkasan Perubahan

Batch 30 merealisasikan integrasi asisten belajar pintar virtual (**"AI Math Companion"**) berbasis **Groq Cloud API** dengan antarmuka 1:1 selaras prototipe `Docs/Ui Template/chatbot/code.html` dan mekanisme pemicu universal **Tekan & Tahan Logo 3 Detik (Long-Press $\ge$ 3s)** di semua layar permainan:

1. **Komponen Pemicu Universal (`LogoLongPressTrigger.cs`):**
   - Mendeteksi interaksi tahanan kursor/sentuh (`IPointerDownHandler`, `IPointerUpHandler`, `IPointerExitHandler`) dengan threshold 3.0 detik berbasis `Time.unscaledDeltaTime`.
   - Menghadirkan micro-animation skala halus (1.05x saat ditekan dan kembali ke 1.0x saat dilepas) dan SFX audio click saat batas 3 detik tercapai.
   - Mengirimkan event global `OnUniversalChatbotTriggered` secara decoupled tanpa merusak fungsionalitas ketukan biasa (< 3 detik).

2. **Klien Layanan Groq Cloud API & Config Manager (`GroqConfigManager.cs` & `GroqApiClient.cs`):**
   - Manajemen konfigurasi cerdas dengan dual loading (membaca disk lokal via `System.IO.File` + fallback runtime `Resources.Load` terisolasi `MethodImplOptions.NoInlining` yang aman dari error ECall saat CLI testing).
   - Pengiriman HTTP POST asinkron via `UnityWebRequest` ke `https://api.groq.com/openai/v1/chat/completions` dengan model default `llama-3.3-70b-versatile` dan fallback `llama-3.1-8b-instant`.
   - Kredensial API Key dari `Docs/Ui Template/chatbot/api` disimpan pada `Assets/Resources/groq_config.json` dan terproteksi penuh dalam `.gitignore` (Pilar 3).

3. **Manajemen Percakapan & Offline Fallback (`ChatSessionManager.cs`):**
   - Mengadopsi persona pedagogis **Prof. Hopper 🦗 (Guru Belalang)** dan **Pip 🐜 (Asisten Semut Ceria)** dengan metode *scaffolding guidance* ramah anak dan representasi objek nyata ($b = \text{boneka}$, $a = \text{anggur}$).
   - Menerapkan rolling window capping 6 riwayat pesan terakhir untuk efisiensi token dan latensi cepat di perangkat seluler.
   - *Graceful Offline Fallback*: Jika perangkat tidak memiliki koneksi internet, sistem menyajikan tips dan panduan aljabar lokal bawaan secara anggun sehingga game utama tetap 100% playable offline (Pilar 7 & Aturan 3 AGENTS.md).

4. **Pengontrol Antarmuka Pengguna (`ChatbotUIController.cs`):**
   - Manajemen tampilan modal Canvas overlay (SortingOrder 100) dengan Dark Backdrop.
   - Header kayu fantasi, logo AlgeCard, avatar karakter, dan status Online hijau emerald.
   - Balon pesan perkamen untuk bot dan balon biru 3D untuk pesan pemain.
   - 3 Quick Prompt Chips (*"💡 How to isolate x?"*, *"🔍 What is a variable?"*, *"📜 Hint for current mission"*).
   - Bilah input perkamen krem dan tombol kirim 3D hijau emerald.
