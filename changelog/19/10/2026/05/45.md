# Changelog — 19 Oktober 2026 05:45 WIB (Batch 23)

## Batch 23: Resolusi Eror Input System (`UnityEngine.Input.get_mousePosition`) & Interaktivitas Layar 05 & 06

### 📌 Ringkasan Masalah & Permintaan Pengguna
Menindaklanjuti tangkapan layar Unity Editor Play Mode yang diunggah oleh Yogi Ario pada Layar 05 (`05_TrueOrFalse.unity`) dan Layar 06 (`06_ScoreResults.unity`):
1. **Akar Masalah Eror Konsol 999+:**
   - Konsol memunculkan ratusan hingga 999+ eror: `InvalidOperationException: You are trying to read Input using the UnityEngine.Input class, but you have switched active Input handling to Input System package in Player Settings. UnityEngine.Input.get_mousePosition ()`.
   - Objek `EventSystem` pada kedua scene tersebut masih menggunakan GUID komponen legacy `StandaloneInputModule` (`guid: 4f231c4fb786f3946a6b90b886c48677`).
   - Karena setelan `activeInputHandler: 1` mengaktifkan New Input System Package dan mematikan Legacy Input Manager, pemanggilan `UnityEngine.Input.mousePosition` setiap frame oleh `StandaloneInputModule` melempar `InvalidOperationException` secara terus menerus dan melumpuhkan deteksi interaksi klik/tap.
2. **Isu Hierarki & Raycast Target:**
   - Pada `05_TrueOrFalse.unity`, ditemukan 38 transform anak yang memiliki `m_Father`, namun tidak terdaftar pada array `m_Children: []` induknya. Akibatnya, `GraphicRaycaster` UGUI berpotensi mengabaikan tombol interaktif (`NextQuestionButton`, `SkipCountdownButton`, `BackButton`).
   - Panel latar belakang dan teks dekoratif memiliki `m_RaycastTarget: 1`, berisiko menelan klik pointer.
   - Canvas pada kedua scene masih menggunakan `RenderMode: 1` (Screen Space Camera) alih-alih `RenderMode: 0` (Screen Space Overlay).
