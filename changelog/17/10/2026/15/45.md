# Changelog — 17/10/2026 15:45 WIB

## 🐛 Bug Fixes & Perbaikan Visual 01_SplashScreen
- **Perbaikan GUID Komponen Visual UI**: Memperbaiki GUID skrip komponen `Image`, `Text`, `Button`, `Outline`, dan `EventSystem` pada scene `01_SplashScreen.unity` ke GUID resmi Unity 6.
- **Normalisasi Skala Canvas**: Memperbarui `localScale` RectTransform Canvas dari `(0, 0, 0)` menjadi `(1, 1, 1)` sehingga seluruh visual anak Canvas berdimensi normal.
- **Migrasi Input Module**: Mengganti `StandaloneInputModule` (legacy) pada `EventSystem` dengan `InputSystemUIInputModule` bawaan paket New Input System (`com.unity.inputsystem`) dan `DefaultInputActions`.
- **Pengamanan Input Controller**: Menambahkan preprocessor `#if ENABLE_LEGACY_INPUT_MANAGER` pada `SplashScreenController.cs` untuk mencegah `InvalidOperationException` saat New Input System aktif.
- **Reset Offset Safe Area**: Memperbarui `SafeAreaFitter.cs` agar mereset `offsetMin` dan `offsetMax` ke `Vector2.zero` saat menerapkan safe area.
- **Sinkronisasi PlayerSettings**: Mengatur `activeInputHandler: 2` (Both) di `ProjectSettings/ProjectSettings.asset` untuk kompatibilitas input maksimal.
- **Penambahan Test Case**: Menambahkan unit test `TC_UI_04_SafeArea_ApplySafeArea_ResetsOffsetsToZero` di `SafeAreaAndNavigationTests.cs` (total 18 unit tests).
- **Pencatatan Keputusan**: Mencatat keputusan arsitektural `DEC-16` di `Docs/Decision_Log.md`.
